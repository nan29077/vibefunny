# VIBEFUNNY 테스트 시나리오

개발 서버: `npm run dev` → http://localhost:3001

`admin@vibefunny.com / Admin1234!` 로 로그인하여 정책을 조정한 뒤, 별도 브라우저(또는 시크릿 창)에서 일반 계정으로 각 플로우를 검증합니다.

## A. 자동 검증 (이미 통과)
- `npm run build` — 35개 라우트 컴파일 성공.
- 핵심 ledger 로직 단위 시나리오 9/9 통과:
  - 가입비 결제 → 일반회원 → 바이브회원 전환 + 멘토 추천 수당 = 관리자 정책 고정 금액(1회, 1단계)
  - 포인트 충전 잔액 반영

## B. 수동 시나리오

### 1. 크리에이터 가입 (추천인 코드 필수)
1. `/signup` → 크리에이터 선택 → 추천인 코드(바이브회원 또는 관리자 "회사 추천 코드") 입력 필수.
2. 가입 완료 → **일반회원**으로 대시보드 진입(로그인·대시보드·프로필/SNS 계정·문의만 가능).
3. 추천인 코드 없이·일반회원의 코드로는 가입 불가 확인.

### 2. 가입비 + 일반회원 → 바이브회원 + 멘토 확인
1. admin → `정책 설정` → 크리에이터 "가입비 사용" 체크, 금액(예: 990,000원)·추천 수당(고정 금액) 저장, 추천 수당 지급 ON.
2. 바이브회원 A의 추천 코드로 새 크리에이터 B 가입 → 결제 페이지(나중에 결제 가능) → B는 **일반회원**.
3. B로 캠페인 참여·영상 제작 의뢰·쇼츠 커머스·AI 숏츠·출금·SNS 맞구독 시도 → "바이브회원 전용" 안내로 차단.
4. A의 `내 멘티 현황`에 B가 **결제 전 · 일반회원**으로 표시.
5. B가 가입비 결제 → B **바이브회원**, A 화면에 **결제 완료** + 결제일, A에게 알림, A의 `수익/출금`에 추천 수당 지급 대기 생성.
6. admin `회원 관리`의 일반회원/바이브회원 탭, 회원 상세의 가입비 결제·멘티 목록 확인.

### 3. 제작 의뢰 (관리자 배정·검수)
> 현재 제작 의뢰를 새로 만드는 UI는 없습니다. 시드/데이터로 생성된 의뢰로 검증합니다.
1. 바이브회원 creator `제작 의뢰`에서 참여 신청 (일반회원은 차단).
2. admin `제작 의뢰`에서 작업자 배정.
3. creator 결과물 URL 제출.
4. admin 검수 → 승인 → creator 정산 확인.

### 4. 광고 캠페인 + 실행사 수수료
1. advertiser(실행사) 가입 → `대행사/수수료`의 추천 코드 확인.
2. 다른 계정을 advertiser(대행사)로 가입하며 실행사 코드 입력 → 상위 실행사 연결. ('추천인 없음' 체크로도 대행사 가입 가능 — 이 경우 실행사 수수료 없음)
   - 광고주 유형은 가입 시 선택값으로 고정되며, 포인트 100만원 이상 충전해도 자동으로 실행사가 되지 않음을 확인.
3. 대행사 `포인트` 300,000 충전(성공).
4. 대행사 `캠페인 만들기` → 비용 자동 계산 → 포인트 차감 → 관리자 승인 대기.
5. admin `캠페인 승인/노출` → 승인.
6. creator `광고 캠페인` → 참여 → (admin/광고주 승인) → 증빙 제출.
7. admin/광고주 증빙 승인 → creator 수익 정산.
8. 실행사 `대행사/수수료`에 수수료(기본: 대행사 차감액 × 5%) 생성 확인.

### 5. 출금
1. creator `수익/출금` → 출금 신청.
2. admin `정산/출금` → 승인 → 지급완료.

### 6. 반응형
- 브라우저 폭을 좁히면 사이드바 → 상단 햄버거 + 하단 탭 메뉴로 전환.

## C. 2026-10-31 수정분 확인 시나리오
1. **캠페인 모집 종료일 필수**: 캠페인 만들기 2단계 '모집 종료일'은 기본 30일 뒤로 채워짐. 비우면 '다음' 비활성, 서버도 거부.
2. **실행사 수수료 회수**: 대행사 캠페인 승인(실행사 +5%) → 실행사가 포인트를 다 쓴 뒤 대행사가 취소 → 실행사 잔액이 마이너스로 표시되고 다음 충전에서 상계, 마이너스 동안 캠페인 등록 불가.
3. **영상 다운로드 후 취소 제한**: 배포 참여자가 배정 영상을 내려받으면 광고주는 전액 취소·선발 취소 불가(관리자는 가능).
4. **분쟁 1회**: 같은 참여 건에 회원 분쟁은 1회까지, 크리에이터는 완료(지급)된 작업에 분쟁 불가.
5. **추천 수당**: 새 DB는 추천인 제도 ON. OFF 상태에서 결제한 멘티는 관리자 `추천 수당` 화면의 '수당 미생성 멘티'에서 수당 생성 가능. 지급·취소 시 멘토 알림.
6. **정책 입력 검증**: 음수·범위 밖 금액은 저장되지 않고 빨간 안내, 광고주 청구액 < 크리에이터 지급액이면 노란 확인 안내.
7. **최소 출금액**: 정책 설정 '출금 정책'(기본 10,000원) 미만 출금 신청 거부.
8. **포인트 직접 충전**: 1,000원 단위만 허용.
9. **고객센터**: 회원 문의 시 관리자 알림 + 대시보드 '회원 문의 답변 대기'. 기본 '평일에만 운영'(주말엔 문의 입력 닫힘, FAQ는 열람 가능).
10. **제작 의뢰 마감**: 마감일(한국 시간 자정 기준)이 지나면 '모집 마감' 표시·신청 거부, 미선정 신청자 알림.
